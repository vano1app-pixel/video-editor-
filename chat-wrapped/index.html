How to export a WhatsApp chat

  1. Open the group chat
  2. Tap the group name → scroll down → Export chat
  3. Choose Without media
  4. Save the .txt and drop it above

Your chat is parsed in your browser. Message text never gets uploaded — only aggregate counts and a small anonymised sample are sent to write the jokes. Nothing is stored.
